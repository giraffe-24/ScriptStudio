## この回のいちばんの発見

視聴者が混乱しているのは「容量が2つある」ことに気づいていない点。

```
  ①Googleの保管庫（無料15GB）        ②スマホ本体の容量
  Gmail・ドライブと共有              端末の中の空き
  ─────────────────                ─────────────────
  ここが満杯 → 写真が                ここが満杯 → 新しい
  バックアップされなくなる            写真が撮れなくなる
      ↓ 打ち手                          ↓ 打ち手
  消してよさそうな候補から捨てる      このデバイスの空き容量を増やす
  保存画質を見直す                    （保管庫の実物は残る）
```

「どっちの容量が足りないのか」を先に分けてやるのが、この回の価値。旧EP104では前振りの一言で済ませていたが、容量が主題になるなら独立した章にする。

## 前振り（約450字）

### セクション0：減らす場所は2つある
- 結論：容量には2つある。どっちで困っているかを先に分けると、やることが決まる
- 展開：まずGoogleフォトの仕組み＝撮った写真をインターネット上の保管庫に自動でコピーする（これをバックアップと呼ぶ）→ だから容量も2か所（Googleの保管庫／スマホ本体）→ Googleの保管庫は無料で15GB、これはGmailとGoogleドライブと共有なので、写真で使い切るとメールにも影響が出る
- 役割：以降の3つの打ち手が、どっちの容量に効くのかを読者が自分で選べるようにする

## 本題（約2,300字）

### セクション1：消してよさそうな候補から捨てる（約600字）〔その1・Googleの保管庫〕
- 結論：Googleが挙げてくれた候補から、まとめて捨てる。1枚ずつ見返さない
- 手順概要：「ストレージを管理」または雲アイコンを開く → ぼやけた写真・スクリーンショット・サイズの大きい動画などが種類ごとに並ぶ → まとめて選んで削除
- 補足：消しても30日はゴミ箱（コレクション→ゴミ箱）から戻せる。表示の並びは環境で変わる

### セクション2：スマホ本体の空き容量を増やす（約600字）〔その2・スマホ本体〕
- 結論：本体がきついなら「このデバイスの空き容量を増やす」。写真の実物は保管庫に残る
- 手順概要：プロフィール写真をタップ →「このデバイスの空き容量を増やす」→ バックアップ済みで30日以上経過した写真が本体から消える → 消したあともGoogleフォトを開けば今までどおり見られる
- 補足：使う前の条件はバックアップが済んでいること。iPhoneはこのあと写真アプリの「最近削除した項目」も空にする（ここを飛ばすと本体の空きが増えない。公式に明記あり）

### セクション3：保存画質を見直す（約550字）〔その3・これから増やさない〕
- 結論：普段の使い方なら「保存容量の節約画質」でよい。足りるかどうかはここでほぼ決まる
- 手順概要：プロフィール写真 → 設定 → バックアップ →「写真と動画の画質」→ 選択肢は「元の画質」「保存容量の節約画質」「高速」
- 補足：節約画質は16MP超を16MP、1080p超を1080pに縮小。スマホやテレビで見る分には違いがほぼ分からない。大きく引き伸ばして印刷する人以外は節約画質で十分。「高速」は3MP・480pまで下がるのでおすすめしない

### セクション4：見返すついでに消す（約500字）〔習慣化〕
- 結論：整理の時間は取らない。たまに眺める「ついで」に、星と削除を済ませる
- 手順概要：いいなと思った写真は星（お気に入り）→ いらない写真はその場で削除 → 消すのはブレ・連写の重複・用済みスクショの3種類だけ → お気に入りはコレクションから一覧できる
- 補足：判断は「もう一度見たいか」「もう要らないか」の2択で、分類はしない。義務ではなく気が向いた分だけ。お茶を飲みながら思い出を眺める時間が、そのまま整理の時間を兼ねる
