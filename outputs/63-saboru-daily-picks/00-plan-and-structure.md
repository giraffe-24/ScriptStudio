# 企画書：賢くサボる「毎日の手間を消す」買ってよかったもの6選（Amazonスマイルセール連動・8月下旬）

## テーマ分析

### 本質
- 題材：あらきりが毎日使って「手間が減った」と実感した6商品の紹介
- 解決する課題：40-60代の「毎日の名もなき手間」（洗い物・地味な作業の中断・体調管理の面倒）と、いいモノ探し・失敗回避の面倒
- このテーマを今やる理由：8月下旬のスマイルセール＝「今買う理由」を作れるタイミング

### ブランド適合性
- Google系/無料ツールではない（物理商品のため主軸カテゴリからは外れる）
- GO条件「自分が実際に使って良かったもの（毎日使用）」を満たす
- コア哲学「楽して結果を出す・最小の手間で最大の効果・ズボラ」の実演回として成立
- 位置づけ：モノ紹介回ではなく「手間を消す道具・習慣を賢くサボる目線で選ぶ」哲学の実演

## 確定した切り口：A×Cミックス

「毎日の"名もなき手間"を消すもの」を、「賢くサボる人の選び方」つきで渡す。
各商品は必ず次の型で語る（1商品＝1手間削減）。

- A要素（手間削減）：before（この地味な手間が毎日あった）→ after（このモノで消えた・毎日使ってる実感）
- C要素（選ぶ基準）：だから選ぶときはここを見れば失敗しない、という持ち帰れる基準
- セールで狙うときの一言（今買う理由）

締めで「賢くサボる人は"手間が消えるか"と"選ぶ基準"で選ぶ」とメタでまとめ、C軸を効かせる。

裏テーマ：シェイカー＋クエン酸＋ブルーベリー（＋みそ汁）は「毎日の栄養・水分・体調を手間なく整える」で束ねられる。

## 企画メタ

- 想定視聴者：40-60代・非IT寄り。毎日の地味な手間にうっすらストレスがあり、モノ選びに時間をかけたくない層
- 悩み（pain）：名もなき手間の蓄積／いいモノを探すのが面倒／買って失敗したくない
- 得られる価値（promise）：毎日使って手間が減った6品を「消える手間」と「選ぶ基準」つきで知り、セール中に迷わず選べる
- 想定尺：8〜10分目安。6商品あるため各商品は簡潔に（1商品あたり短く保ち、全体3001〜4200字に収める。超過しそうなら商品ごとの脱線を削る）

### キーポイント（keyPoints）
- 主役は「消える手間」と「選ぶ基準」。スペックの羅列にしない
- 全商品「毎日使ってる」検証済みだけ。デメリットも正直に言う
- セール＝今買う理由、モノ＝普遍価値の二層。セール後も効く資産動画にする

## 競合分析

### 一般的な切り口
- 「Amazonセールで買うべきおすすめ○選」＝スペック・価格の羅列型
- 商品レビュー系＝メリット/デメリットの網羅

### 差別化ポイント
- あらきりならでは：主役が商品ではなく「どの手間が消えるか（選んだ理由）」
- ズボラ軸：before→afterで語る。毎日使ってる実感が信頼の核
- 40-60代向け：生活動作に密着した商品に絞り、専門スペックを語らない

## 商品ごとの素材（A：消える手間 / C：選ぶ基準 / トーク素材）

1. エペイオス 音波歯ブラシ ET003（フィリップスと中立比較）
   - A：丁寧に磨く手間・磨き残しの不安を自動化。180日充電で充電の手間も少ない
   - C：防水で丸洗いできるか／充電のもち（180日）／替えブラシの入手性とコスパ（替えブラシ2本付属）
   - トーク素材：エペイオスとフィリップスを比較。セールなら約2000円の価格差。30秒ごとに振動が1秒止まる（磨く場所の切り替え目安）。替えブラシ2本付き
   - ガード：フィリップスを下げない中立比較。価格差・機能は事実ベースで
2. HALEO CYCLO シェイカーボトル 900ml
   - A：洗い物のストレス。分離して手を入れて奥まで洗える。900mlの大容量で何度も詰め替えなくてよい
   - C：食洗機・お湯対応か／口が広い（手が入る・分離できる）か／密閉性とこぼれにくさ／容量
   - トーク素材：キャップがひとひねりで開閉できる手軽さと高い密閉性を両立。こぼれにくい飲み口でスマートな水分補給。「水分をこまめに取る大切さ」を絡める
3. お疲れさんにクエン酸 1L（10倍希釈）
   - A：疲労ケアや飲み物選びを毎回考える手間。薄めるだけ。10倍希釈で1本が長持ち＝買い足し頻度が減る
   - C：希釈タイプのコスパと保存性／続けやすい味・アレンジ幅
   - トーク素材：水や炭酸水で低カロリーのジュース感覚。お酒の割り材にも。牛乳に入れるとヨーグルトドリンク風。クエン酸の一般的な良さに触れる
   - ガード：健康効能は断定しない（薬機法・景表法）。「一般に言われる」「私はこう使っている」の範囲に留める
4. マルコメ 即席みそ汁 減塩 36食（＋乾燥わかめ・デキストリン）
   - A：だしを取る・作る手間。お湯を注ぐだけ。減塩で塩分の罪悪感も減る
   - C：食数（ストック性）／減塩など健康配慮／味・アレンジ性
   - トーク素材：食事の最初に飲むと食べ過ぎ対策になる。乾燥わかめとデキストリンを足すと食物繊維も取れる
   - ガード：「最強」など誇張語は使わない。ダイエット・健康効果は断定せず体験ベースで
5. 冷凍ブルーベリー 500g
   - A：洗う・切る手間ゼロ。冷凍で保存が楽・無駄が出ない
   - C：冷凍か／量とコスパ／そのまま or アレンジしやすいか
   - トーク素材：そのままでもよいが冷たく硬いので知覚過敏の人にはつらい。あらきり流はカップにブルーベリー3cmほど＋水200ml＋電子レンジ30秒、プロテインを加えて飲む。朝を軽く済ませたい人向け。夜は満腹で食べ切れないことがあるので朝食ルーティンに入れるのがおすすめ
   - ガード：目・健康への効能は断定しない（薬機法）。良さは一般論＋体験の範囲で
6. GPD MicroPC2（番外・仕事道具として正直に）
   - A：重いノートを持ち歩く手間。490gでフルスペックPCが持ち出せる
   - C：重さ／端子（RJ45・HDMI・USB）／携帯性とスペックの両立
   - 注意：明確に玄人向け。「万人向けではないけれど私の仕事道具」と正直に出し、気になる人だけ向けと断る（信頼トリガー「デメリットも正直に言う」を活かす）
