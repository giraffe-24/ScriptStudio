# 企画書：Googleフォト整理術（草案）

> 発案根拠（2026-09-14 自チャンネル実測）：歴代1位「Googleカレンダー×メモ×Todo活用」25,915回・2位「Googleドライブ フォルダ3つ整理術」14,759回の共通型＝「Google定番サービス × 整理・活用 × ズボラ訴求 × 数字の約束」。隣接テーマ「スマホ容量パンパン」も2,098回の実績。写真整理はこの型で未出の最後の大物。

## テーマ分析

### 本質
- ツール/サービス：Googleフォト（無料・iPhone/Android/PC対応）
- 解決する課題：写真が何千枚もたまって目当ての1枚が探せない。容量警告におびえながら、整理は面倒で手つかず
- このテーマを今やる理由：ドライブ整理術ヒットの続編ポジションを最短で取れる。家族写真・スクショ・レシートが混ざる40-60代の悩みは季節を問わず常時需要

### ブランド適合性
- [x] Google系/無料ツールである
- [x] ズボラ向けに簡略化できる（「整理しない」が結論なので最もズボラ向き）
- [x] 複雑でもリターンが大きい（一度仕組み化すれば一生もの）

## 競合分析

### 一般的な切り口
- 機能の網羅解説（バックアップ設定・共有・編集まで全部）
- 容量削減テクニック集（画質変更・不要データ削除）
- 初期設定チュートリアル

### 差別化ポイント
- あらきりならでは：「フォルダ分けを頑張らない」という整理思想から入る。機能紹介ではなく「やらないことを決める」構成
- ズボラ軸での独自性：やることをルール3つに限定し、月1回のメンテだけで回る仕組みを約束
- 40-60代向けの配慮：家族写真・孫の写真・レシートやスクショの混在という実生活の文脈で説明。ドライブ整理術ヒットと同じ言葉遣い（グチャグチャ/一生/シンプル）で「あの動画の写真版」と伝わる

## 切り口提案

### 切り口A：Googleフォトがグチャグチャな人へ｜ルール3つで一生スッキリの写真整理術（推奨）
- 想定視聴者の課題：写真が数千枚。アルバム整理を試みては挫折。目当ての写真が探せず、容量警告も気になっている
- 動画で得られる価値：フォルダ分けゼロで「探せる・見返せる・あふれない」状態を、ルール3つ＋月1メンテで維持できる
- 推奨台本タイプ：A（課題解決型）
- フック案：「スマホの中に写真、何千枚ありますか。実は、頑張ってアルバム分けする必要はないんです。Googleフォトは『整理しない』のが正解でした」

### 切り口B：Googleフォトの神機能10選｜写真探し・容量不足がぜんぶ楽になる
- 想定視聴者の課題：Googleフォトを「写真が並ぶだけのアプリ」と思っていて、検索・管理機能を使っていない
- 動画で得られる価値：知らなかった機能をまとめて把握でき、今日から使い始められる
- 推奨台本タイプ：B（網羅型）
- フック案：「そのアプリ、実は写真を『探せる』アプリだって知ってましたか」

### 切り口C：「空き容量がありません」が出た人へ｜写真を消さずに解決するGoogleフォト活用術
- 想定視聴者の課題：スマホの容量警告が出ているが、思い出は消したくない。何を消していいか判断できない
- 動画で得られる価値：思い出を残したまま容量問題を解消する手順が分かる
- 推奨台本タイプ：A（課題解決型）
- フック案：「『空き容量がありません』。この表示、写真を消さなくても消せます」

## 推奨

推奨案：切り口A

理由：
1. 歴代1位・2位と同じ勝ち型（Google定番 × 整理 × ズボラ × 数字の約束）を正面から踏襲でき、ヒットの再現性が最も高い
2. 切り口Cの容量不安・切り口Bの検索機能を、ルール3つの中に自然に内包できる（AはBとCの上位互換になる）
3. 網羅型（B単体）は直近実測で弱い群（小技・設定系は平均約230回）に落ちるリスクがある

### 目次案（切り口A・構成確定版）

# 構成案：Googleフォトがグチャグチャな人へ｜ルール3つで一生スッキリの写真整理術

## 基本情報

| 項目 | 内容 |
|------|------|
| 台本タイプ | A（ツール活用型・課題解決） |
| 想定時間 | 約7分 |
| 想定文字数 | 約3,400〜3,800字 |
| セクション数 | 6セクション |

時間配分の目安：導入 約400字 / 本題 約2,700字 / まとめ 約350字（合計3,001〜4,200字に収める）

## 導入（約400字）

### フック
- タイプ：問いかけ型＋共感型
- 内容：「スマホの中に写真、何千枚ありますか。実は、頑張ってアルバム分けする必要はないんです」

### 課題提示
- アルバム整理を試みては挫折。目当ての1枚が探せない
- 「空き容量がありません」の警告も気になるが、何千枚も見返して消す気力はない

### 解決提示
- Googleフォトは「整理しない」のが正解。守るのはルール3つ、メンテは月1回5分だけ

### 価値リスト
1. 目当ての1枚が、探さなくても数秒で出てくる
2. アルバム分けの迷いと罪悪感が消える
3. 容量警告におびえなくなる

### 宣言
- 「今回はGoogleフォトを『整理しない』で使いこなす、ルール3つを紹介します」
- 視聴継続：「ズボラな私でも実施できているので、是非最後まで見てみてください」

---

## 本題（約2,700字）

### セクション1：フォルダ分けをやめていい理由（約400字）
- 結論：写真整理に挫折するのは本人のせいではなく、フォルダ分けという方法が写真に向いていないから
- 展開：フォルダ分けが破綻する理由（撮る量に分類が追いつかない・1枚が複数分類にまたがる）→ Googleフォトは検索で見つける前提の設計だと宣言
- 補足：Gmail回のヒットフレーズ「ズボラな人ほどフォルダで仕分けることはやめたほうが良い」と同じ思想で、チャンネルの一貫性を出す

### セクション2：目当ての1枚は「探す」でなく「検索」で出す（約500字）
- 結論：スクロールで探すのをやめ、検索窓に生活の言葉を入れる
- 手順概要：検索窓の場所 → 「猫」「ラーメン」など被写体で検索 → 場所（旅行先の地名）で検索 → 人物（顔）で検索 → 写真内の文字でも探せることを実演
- 補足：検索対応の範囲（人物・場所・被写体・文字）は執筆前に fact-checker で現行仕様を確認（下の事実確認リスト）

### セクション3：ルール1：アルバムは3つだけ作る（約500字）
- 結論：アルバムは「見返す用・記録用・人に見せる用」の3つだけ。それ以外は作らない
- 手順概要：アルバムの作り方 → 3つの使い分け基準 → 迷ったらアルバムに入れない（検索で出るから困らない）
- 補足：ドライブ整理術ヒット（フォルダ3つ）と同じ「3つだけ」の約束で、続編性を明示する

### セクション4：ルール2：お気に入りマークで「あとで見る」を一瞬にする（約400字）
- 結論：アルバムに入れるか迷う時間を、スター1タップで置き換える
- 手順概要：スターの付け方 → 付ける基準（もう一度見たいと思った瞬間の1タップ）→ お気に入り一覧の開き方
- 補足：「分類」ではなく「印を付けるだけ」なのでズボラでも続く、が言いたいこと

### セクション5：ルール3：月1回、不要写真の候補を捨てるだけ（約500字）
- 結論：メンテは月1回、Googleフォトが挙げてくれる不要候補（スクショ・レシート類）を捨てるだけ。所要5分
- 手順概要：ストレージ管理機能の場所 → 候補（サイズの大きい写真・スクショ等）の確認 → まとめて削除 → ゴミ箱の保持日数の説明（誤削除しても戻せる安心）
- 補足：機能の現行名称・画面位置・ゴミ箱保持日数は執筆前に fact-checker で確認（仮の名称のまま執筆しない）

### セクション6：容量が心配なときの保存画質の選び方（約400字）
- 結論：無料15GBで足りるかは保存画質の設定で決まる。どちらを選ぶべきかの結論を先に言う
- 手順概要：設定の場所 → 2つの画質の違い（画質と容量のトレードオフ）→ 40〜60代の使い方ならどちらが良いかの結論
- 補足：15GBがフォト・ドライブ・Gmail共通である点、画質モードの正式名称は執筆前に fact-checker で確認
